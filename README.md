# PreGradien

Zero-UI automatic crossfades for SoundCloud. When a track nears its end, PreGradien blends into the next one with a 6 s DJ-style transition.

## Features

- Automatic 6 s crossfade between tracks, with no buttons or settings
- BPM beat-matching with ±4% tempo sync
- Bass swap during the transition
- Leading-silence trimming on the incoming track
- Loudness matching applied to the crossfade only

## Install

1. Download `PreGradien.zip` from [Releases](https://github.com/dominpin/PreGradien/releases) and unzip it, or clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the extension folder.
5. Open soundcloud.com and play a playlist.
